# Images for the new raiseai.in pages

Drop photos into the folder that matches. Antigravity uses them where the drafts in `/handoff` show striped grey boxes.
Anything not here yet stays hidden on the live site, so the build can start before all photos are ready.

| Folder | What goes in it | Size and format |
|---|---|---|
| `founder/` | Hadhi's photos | See founder/README.md |
| `students/` | One photo per student, plus `student-reviews.md` | Square, about 800 x 800, JPG |
| `team/` | Team photos for the About page | Square, about 800 x 800, JPG |
| `about/` | Class, office and event photos for the About page | Landscape, about 1600 px wide, JPG |
| `results/` | Cover images (posters) for student videos | 1280 x 720 (16:9) or 1080 x 1920 (9:16), JPG |
| `logo/` | Logo files | SVG best, else PNG with no background |
| `../video/` | Short student clips, 60 seconds or less | MP4. Longer videos go on YouTube; put the link in `student-reviews.md` |

File names: lowercase, words joined with a dash, no spaces. Example: `anjali-nair.jpg`.
Only use photos, reviews and videos the person has agreed to share.
