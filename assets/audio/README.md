# Audio Testimonials / Voice Notes

Place your voice review `.mp3` or `.m4a` files here.

### Recommended Specs:
- **Format:** MP3 (.mp3) or AAC (.m4a)
- **Bitrate:** 64 kbps to 128 kbps (plenty for voice notes, keeps file size around 100 KB – 400 KB)
- **Names (example):**
  - `jithin.mp3`
  - `vishnu.mp3`
  - `attendee-1.mp3`
  - `testimonial-1.mp3`
